xconf — one client, three servers

Manage a keyed list of example:system instances (list system { key name; leaf hostname; }) over NETCONF, RESTCONF, and CORECONF.

Pick an instance from the dropdown, then SET its hostname. ADD creates a new instance (name + hostname), REMOVE deletes the selected one, and GET ALL lists every instance on that server. RESET restores the datastore to a single default instance.
Result window legend: ■ command (what you asked) · ■ sent (wire request) · ■ received (server response; red on error).
